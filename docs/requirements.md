# Requerimientos Funcionales

## RF-01 · Autenticación y Registro

| ID | Requerimiento |
|----|---------------|
| RF-01 | El sistema debe permitir que un usuario inicie sesión y mantenga una sesión activa. |
| RF-02 | El sistema debe permitir que un usuario se registre en un círculo. |
| RF-03 | El sistema debe generar sugerencias de inscripción a círculos basadas en los intereses del usuario autenticado. |

---

## RF-02 · Actividades y Calendario

| ID | Requerimiento |
|----|---------------|
| RF-04 | El sistema debe permitir registrar actividades para su difusión entre los miembros. |
| RF-05 | El sistema debe mostrar un calendario de actividades programadas. |
| RF-06 | El sistema debe mostrar un calendario de reuniones del círculo. |

---

## RF-03 · Sesiones y Materiales

| ID | Requerimiento |
|----|---------------|
| RF-07 | El sistema debe permitir registrar la asistencia de los participantes a sesiones. |
| RF-08 | El sistema debe permitir entregar feedback asociado a sesiones. |
| RF-09 | El sistema debe permitir subir material relacionado a actividades. |
| RF-10 | El sistema debe mostrar un repositorio de materiales disponibles para los miembros. |

---

## RF-04 · Comunicación y Foro

| ID | Requerimiento |
|----|---------------|
| RF-11 | El sistema debe permitir registrar entradas en el foro del círculo. |
| RF-12 | El sistema debe permitir enviar anuncios y mostrar la lista de anuncios publicados a los miembros. |
| RF-13 | El sistema debe enviar mensajes dirigidos a miembros específicos de un círculo. |

---

## RF-05 · Perfiles e Información de Círculos

| ID | Requerimiento |
|----|---------------|
| RF-14 | El sistema debe mostrar el perfil de cada miembro del círculo. |
| RF-15 | El sistema debe mostrar información general sobre los círculos disponibles. |

---

## RF-06 · Gestión de Membresía

| ID | Requerimiento |
|----|---------------|
| RF-16 | El sistema debe enviar una notificación cuando un miembro es desvinculado de un círculo. |
| RF-17 | El sistema debe permitir registrar convocatorias para los círculos. |
